Cachet. Interactive demo By Alyssa I. Agard

Email signatures, managed in one place.

Design an organization's email signatures once. Cachet fills in each person's details from Microsoft 365 and inserts the right signature automatically whenever anyone writes in Outlook.

A working simulation with a fictional organization and sample people. No sign-in is required, and nothing leaves your browser.

What happened

  1. Start a message to see each step.

An administrator designs templates

Text, links, icons, a logo, and a legal disclaimer, built in Cachet's editor with a live preview. Placeholders such as {{title}} fill in for each person.

Microsoft 365 provides the details

Cachet reads people, titles, phone numbers, groups, and shared mailboxes from the directory with read-only permission, on demand or nightly.

Someone starts an email

Outlook starts Cachet's add-in automatically for new messages, replies, forwards, and meeting invitations, and when the From address changes.

Cachet confirms who is asking

The add-in sends a Microsoft-issued sign-in token. Cachet checks that it is genuine, unexpired, meant for Cachet, and from an organization it serves.

Cachet picks and fills the template

It checks the person's own setting, groups, domain, and organization default in order, fills in their details, and drops anything empty.

The signature appears

The add-in inserts email-safe HTML that displays consistently across mail programs, in Outlook on the web, Windows, Mac, iPhone, and Android.

A safety net on the server

Generated Exchange mail rules sign any message the add-in missed. They skip messages already signed and apply only to mail sent from inside the organization, so forged outside mail never receives a real signature.

Security by design

  • Every record belongs to one organization, and each request is limited to it.
  • Each site serves only the Microsoft 365 organizations it lists.
  • Links are limited to web, email, and phone addresses, and all template content is validated on save.
  • Cachet never holds Exchange administrator rights.

Built with

  • Next.js and React for the admin site
  • PostgreSQL for the data
  • Microsoft Entra ID and Microsoft Graph for sign-in and the directory
  • The Office add-in platform for Outlook
  • Azure Container Apps for hosting

About this demo

Cachet runs in production at Agard Research Associates Inc. Because visitors cannot sign in to that organization, this page recreates the experience in the browser with a fictional one. The real application stores templates in a database, verifies every request, and runs inside Outlook. I designed and developed Cachet.
